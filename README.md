# 🇸🇦 Assassin's Creed 1 - Arabic Localization Overhaul
نسخة محسنة ومطورة بالكامل لتعريب الجزء الأول من لعبة Assassin's Creed.

### 🚀 ما الذي يميز هذه النسخة؟
تم العمل على هذه النسخة لتقديم تجربة لعب أفضل وأكثر دقة للاعبين العرب، حيث شمل التطوير:
- 📝 **إعادة ترجمة شاملة:** تمت إعادة ترجمة وصياغة أكثر من **2,620 سطراً** لضمان دقة المصطلحات وتناسبها مع سياق قصة اللعبة التاريخي، بعد اكتشاف أخطاء في النسخ السابقة.
- 🖥️ **إصلاح مشكلة الشاشة (Resolution Fix):** تم حل مشكلة خروج الترجمة خارج إطار الشاشة التي كان يعاني منها الكثيرون. تم ضبط الإحداثيات برمجياً (عبر ملف `SubtitleSynchAC1.ini`) لتعمل بشكل افتراضي ومثالي على شاشات بدقة **1366x768** (تم تعديل `SubtitlePosY` إلى 680.0 و `SubtitlePosX` إلى 683.0 لتوسيط النصوص تماماً).

### 🛠️ طريقة التثبيت
1. قم بتحميل الملف المرفق في هذا المستودع.
2. قم بفك الضغط ونقل الملفات إلى مسار اللعبة الأساسي.
3. **هام جداً:** لا تنسَ تثبيت ملف الخط `subtitles.ttf` داخل نظام الويندوز الخاص بك لضمان ظهور الحروف العربية بشكل صحيح داخل اللعبة.
